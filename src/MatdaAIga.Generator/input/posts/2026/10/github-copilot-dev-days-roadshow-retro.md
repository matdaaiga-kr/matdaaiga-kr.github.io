2026년 10월 15일부터 17일까지 사흘 동안 포항, 부산, 대구를 돌며 **GitHub Copilot Dev Days 로드쇼**를 열었습니다.

![roadshow][image-00]

이번 로드쇼는 [행사 오픈 글][roadshow-open]에서 소개한 대로 실습 행사였습니다. 참가자들은 GitHub Copilot app과 GitHub Copilot CLI를 기초부터 직접 따라 해 보았습니다. 세 지역 모두 유저스틴님의 키노트로 문을 열었고, 실습 환경을 함께 설정한 뒤 두 세션을 진행했습니다. 참가자 모두 100달러 상당의 GitHub Copilot 라이선스를 받아서 행사 당일 내내 마음껏 연습해 볼 수 있었습니다.

실습은 GitHub가 공개한 [GitHub Copilot 워크숍][copilot-workshops] 자료를 바탕으로 진행했습니다. 참가자들은 이 자료를 따라 GitHub Copilot app과 GitHub Copilot CLI로 직접 앱을 만들며 두 도구를 경험했습니다. 이 자료는 누구나 한국어로 볼 수 있어서, 행사에 오지 못한 분들도 혼자 따라 해 볼 수 있습니다.

---

## 키노트 | 유저스틴

![keynote][image-01]

Microsoft와 GitHub에서 수석 Developer Advocate으로 일하는 유저스틴님이 세 지역의 키노트를 모두 맡았습니다. 유저스틴님은 GitHub Copilot이 개발자 생산성을 어떻게 끌어올리는지 소개하고, 이어지는 실습에서 무엇을 경험하게 될지 큰 그림을 보여 주었습니다.

- [유저스틴님이 알려주는 다양한 개발 소식 링크드인에서 받아보기][justin-sns]

---

## 10월 15일 포항 | 포항공과대학교 포스코국제관

![pohang][image-02]

포항에서는 28명이 참여해 주셨습니다! 두 세션을 투트랙으로 동시에 열었습니다. 참가자는 GitHub Copilot app과 GitHub Copilot CLI 가운데 하나를 골라 세 시간 동안 깊이 실습했습니다. 행사 마지막에는 Microsoft 학생 홍보대사 프로그램을 소개하고 현장 등록도 받았습니다.

### 트랙 A. GitHub Copilot CLI | 김근희

김근희님은 [Microsoft 학생 홍보대사][msa]로 활동하고 있습니다. 이번 세션에서는 터미널에서 Copilot으로 일상적인 개발 작업을 더 빠르게 처리하는 방법을 보여 주었습니다.

- [김근희님이 알려주는 다양한 개발 소식 링크드인에서 받아보기][geunhee-sns]

### 트랙 B. GitHub Copilot app | 황지현

황지현님도 [Microsoft 학생 홍보대사][msa]로 활동하고 있습니다. 황지현님은 데스크톱 앱인 GitHub Copilot app으로 개발 흐름을 넓히는 방법을 참가자들과 함께 실습했습니다.

- [황지현님이 알려주는 다양한 개발 소식 링크드인에서 받아보기][jihyeon-sns]

---

## 10월 16일 부산 | 부산문화콘텐츠콤플렉스

![busan][image-03]

부산에서는 15명이 참여해 주셨습니다! 두 세션을 차례로 진행해서 참가자 모두가 app과 CLI를 한 번에 경험했습니다.

### Session 01. GitHub Copilot app | 황지현

포항에 이어 부산에서도 황지현님이 GitHub Copilot app 세션을 맡았습니다.

### Session 02. GitHub Copilot CLI | 윤금재

IT 교육기업 Teamus 대표인 윤금재님은 터미널에서 Copilot CLI로 개발 작업을 처리하는 방법을 소개했습니다.

- [윤금재님이 알려주는 다양한 개발 소식 링크드인에서 받아보기][keumjae-sns]

---

## 10월 17일 대구 | 디노스페이스

![daegu][image-04]

로드쇼의 마지막은 맞다AI가의 홈그라운드인 대구였습니다. 대구에서는 11명이 참여해 주셨습니다!

### Session 01. GitHub Copilot app | 이시영

LG CNS에서 컨설팅 업무를 하는 Microsoft 공인 트레이너 이시영님이 GitHub Copilot app 세션을 진행했습니다.

- [이시영님이 알려주는 다양한 개발 소식 링크드인에서 받아보기][siyoung-sns]

### Session 02. GitHub Copilot CLI | 유저스틴

대구에서는 키노트를 맡은 유저스틴님이 GitHub Copilot CLI 세션까지 직접 진행했습니다.

---

사흘 동안 세 지역에서 함께해 주신 참가자 여러분 모두 고생 많으셨습니다.

이번 로드쇼를 후원해 주신 Microsoft, GitHub, OpenUP과 장소를 빌려주신 포항공과대학교, 부산문화콘텐츠콤플렉스에 감사드립니다.

맞다AI가는 앞으로도 대구와 경북을 넘어 더 많은 지역의 개발자가 최신 AI 기술을 직접 경험할 수 있도록 다양한 행사를 준비하겠습니다. 다가올 11월 행사도 많은 기대 부탁드립니다!
